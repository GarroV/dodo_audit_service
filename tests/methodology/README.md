# Учебная методика для тестов

Набор иллюстративный. Собран для прогона тестов и НЕ описывает методику управляющей компании: формулировки, названия зон, критерии и подсказки здесь выдуманы. Совпадают только идентификаторы — ими связаны сущности продукта (`CLAUDE.md`).

Illustrative fixture for the test suite. It does NOT describe any real audit methodology: wordings, zone names, criteria and photo cues are invented.

Зачем она есть (T141, T146):

* **Тесты не читают боевую методику.** Она лежит вне git (D002) и её правит
  управляющая компания. Пока набор тестов читал её, добавленное в данные слово
  красило сборку — правка чужих данных ломала наш прогон.
* **Боевая методика не цитируется в git.** Репозиторий публичный, а формулировки
  вопросов, названия зон и строки карты кадров — данные управляющей компании.

Что здесь настоящее, а что выдумано:

* **Настоящие — только идентификаторы**: коды пунктов (`CLN05`), коды зон
  (`hot_kitchen`), классы (`D0`…`D3`), ставки вычетов и пороги букв. Ими продукт
  связывает сущности, они стоят в контрактах блоков и были в репозитории и до
  этого набора.
* **Выдумано всё остальное**: формулировки вопросов и процессов, названия зон,
  критерии, подсказки карты кадров, маршрут обхода.

Кто это читает: фикстуры `domain_env` и `data_copy` в `tests/conftest.py`.
Тесты, которым нужна именно боевая методика (боевой якорь 97.5 %/97 % на
`examples/`), берут её отдельно и помечены `requires_data`/`requires_examples`.
