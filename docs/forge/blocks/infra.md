# Блок: infra

## Назначение

Поднять продукт одной командой там, где он должен жить, и сделать так, чтобы переезд не был переписыванием.

## API-контракт

```bash
docker compose up -d      # поднимает бота
make regress              # прогон движка на эталонных данных
make demo                 # демо-набор на английском
```

Переменные: `TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY`, `AUDIT_DATA_DIR`, `ALLOWED_TELEGRAM_IDS`, `STATE_DIR`, `BOT_MODE` (`polling` | `webhook`), `TZ`.

## Зависимости

`bot`.

## Definition of Done блока

- [ ] Образ `python:3.12-slim` с `ffmpeg`, системными библиотеками WeasyPrint и кириллическим шрифтом.
- [ ] `docker compose up -d` поднимает бота на домашнем сервере; префикс проекта свой, чужие контейнеры не затронуты.
- [ ] `.env.example` со всеми именами переменных закоммичен; настоящий `.env` в git не попадает.
- [ ] Состояние проверок лежит в томе и переживает пересоздание контейнера.
- [ ] Каталог с методикой монтируется снаружи: `data/` в образ не запекается.
- [ ] Часовой пояс задан явно — иначе даты в отчёте уедут относительно местного времени.

- [ ] Смена площадки не требует правок кода: проверено поднятием того же compose локально.
