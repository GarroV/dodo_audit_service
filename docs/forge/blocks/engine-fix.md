# Блок: engine-fix

## Назначение

Довести существующий движок до состояния, в котором на него можно опереться боту. Логику расчёта не трогаем — чиним то, что мешает вызывать движок из программы и то, что уже давало неверный отчёт на боевых проверках.

## API-контракт

Добавляются команды и поведение, остальные вызовы остаются как есть:

```
audit.py edit --n N [--code CODE] [--level D1|D2|D3] [--zone ZONE] [--text "..."]
audit.py init ... --partner "..."     # партнёр попадает в шапку отчёта
report.py pdf --out PATH              # ненулевой код возврата, если файл не создан
report.py letter                      # шаблон по наличию D2/D3
```

Инварианты: повторный `add` с той же парой «код + зона» завершается ошибкой; номера записей сквозные и после `drop` не переиспользуются; `init` отклоняет пустую пиццерию и дату не в формате ISO.

## Зависимости

Нет. Строится первым и параллельно всему остальному.

## Definition of Done блока

- [ ] `audit.py edit` меняет код, класс, зону и формулировку существующей записи; несуществующий номер — внятная ошибка.
- [ ] `report.py pdf` возвращает ненулевой код, если файл не появился на диске; `report.py letter` — если письмо пустое.
- [ ] Повторный `add` той же пары «код + зона» отклоняется, а не создаёт вторую запись.
- [ ] Номера записей сквозные: после удаления последней следующая получает новый номер.
- [ ] `init` валидирует пиццерию и дату; есть команда правки шапки уже начатой проверки.
- [ ] Сроки устранения печатаются в PDF по каждому нарушению.
- [ ] Письмо при проверке без D2 и D3 — короткое, без требования плана действий; при наличии — с планом. Два шаблона, а не один с условными вставками.
- [ ] Партнёр из `init --partner` попадает в шапку отчёта.
- [ ] Запись состояния атомарна: временный файл, `os.replace`, блокировка на чат. Есть тест на параллельную запись двух кадров альбома.
- [ ] `requirements.txt` существует и перечисляет всё, чем движок пользуется.
- [ ] Регрессия зелёная: `belgrade-1` → 97.5 %, A, 5×D1; `belgrade-2` → 97.0 %, A, 6×D1.
- [ ] `docs/04-engine.md` обновлён: исправленные дефекты убраны из списка, новые команды описаны.
