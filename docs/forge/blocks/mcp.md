# Блок: mcp

## Назначение

Дать возможность работать с накопленными проверками через Claude: спросить историю точки, найти повторяющиеся нарушения, собрать сводку по сети. Делается по образцу работающего `swarm-mcp` — Edge Function и личный токен (D055).

## API-контракт

Инструменты MCP, только чтение:

```
list_inspections(unit?, date_from?, date_to?, limit?)   # проверки с фильтрами
get_inspection(id)                                      # проверка целиком с находками
findings_by_unit(unit, limit?)                          # находки по точке
unit_history(unit)                                      # динамика оценок точки
network_summary(period?)                                # сводка по сети
```

Пишущие инструменты — управление чек-листами (D049) — отдельной очередью, после чтения.

## Зависимости

`db`.

## Definition of Done блока

- [ ] Пять инструментов чтения отвечают на боевых данных, ответы сверены с прямым запросом к базе.
- [ ] Доступ закрыт токеном; без него сервер не отдаёт ничего.
- [ ] Ответ инструмента говорит состояние прямо: пусто — это «ничего не найдено», а не молчание.
- [ ] Ни один инструмент не считает оценку заново — проценты и буквы берутся из того, что записано при проверке.
- [ ] Смоук: три вопроса разного типа через Claude, ответы сверены с SQL.
