# Блок: report

## Назначение

Собрать PDF-отчёт и текст письма партнёру так, чтобы это можно было отправить не редактируя.

## API-контракт

```python
build_pdf(chat_id: int) -> Path      # исключение, если файл не создан
build_letter(chat_id: int) -> str    # шаблон по наличию D2/D3
```

## Зависимости

`domain`, `engine-fix`.

## Definition of Done блока

- [ ] PDF собирается WeasyPrint внутри образа, без обращения к рендерерам на хосте.
- [ ] Кириллица отрисована: шрифт лежит в образе, путь указан явно.
- [ ] Нумерация страниц есть.
- [ ] Вид отчёта сверен глазами с эталонами из `examples/` на тех же данных; расхождения устранены правкой CSS.
- [ ] Отсутствующая фотография заметна: сборка сообщает о промахе, а не вставляет пустоту.
- [ ] Провал сборки поднимает исключение, бот показывает аудитору ошибку и не выдаёт файл за готовый.
- [ ] Письмо для чистой проверки и письмо с нарушениями — два разных шаблона.
- [ ] Имя файла остаётся прежним: `Аудит <пиццерия> - <аудитор> - <дд.мм.гггг>.pdf`.
